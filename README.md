Ajaneeshwar. Lead AI Engineer, Chennai.

Hand me a vague business problem and I hand back a deployed system. Sitting with the business team to work out what they actually need, drawing the architecture, writing most of it, shipping it, then keeping it alive in production. That whole arc is the job and I like all of it.

### what i work on

|  |  |
|---|---|
| `voice agents` | real-time speech, turn-taking, barge-in, telephony, orchestration |

Voice is the vertical I have gone deepest on. It is not the whole job.

### opinions i hold

```
latency is a feature. users feel milliseconds before they notice quality.
the interesting bugs live at the boundaries between services, not inside them.
an eval you do not run before every release is a decoration.
a demo that works once is not a system.
if it is not deployed, it is not done.
```

### in the open

Most of what I build lives in private repos. What does not:

**[SpectraHush](https://github.com/Ajaneeshwar/SpectraHush)** · streaming Berouti-style spectral subtraction. classical DSP, no model weights, no GPU, runs inside the audio callback.

**[DenoiseStream](https://github.com/Ajaneeshwar/DenoiseStream)** · real-time mic noise suppression over WebSocket, pluggable backends behind one interface. swap the denoiser without touching the transport.

**[AWS AI Agents](https://github.com/Ajaneeshwar/aws-ai-agents-analytics)** · agentic cloud-cost analytics on Bedrock AgentCore. tool orchestration, code execution, guardrails.

**[ai-engineer-agent](https://github.com/Ajaneeshwar/ai-engineer-agent)** · multi-agent system that reads any repo and reports architecture, bugs and missing tests.
