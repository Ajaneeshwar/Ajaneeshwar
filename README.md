### 👋 hey

I'm **Ajaneeshwar** — Lead AI Engineer, based in Chennai.

I'm the person you hand a vague business problem to and get back a deployed system. Sitting with the business team to work out what they actually need, drawing the architecture, writing most of it, shipping it, and owning the thing in production — that's the whole arc, and I like all of it.

AI products don't respect layer boundaries. The model, the pipeline, the API, the interface and the infrastructure all have to hold together, or none of it ships.

> **system design is the job. the model is a detail.**

### ⚡ opinions I hold

```
latency is a feature — users feel milliseconds before they notice quality
the interesting bugs live at the boundaries between services, not inside them
an eval you don't run before every release is a decoration
a demo that works once is not a system
if it isn't deployed, it isn't done
```

### 📦 in the open

Most of what I build lives in private repos. What doesn't:

**[SpectraHush](https://github.com/Ajaneeshwar/SpectraHush)** — streaming Berouti-style spectral subtraction. Classical DSP, no model weights, no GPU, runs inside the audio callback.

**[DenoiseStream](https://github.com/Ajaneeshwar/DenoiseStream)** — real-time mic noise suppression over WebSocket, with pluggable backends behind one interface. Swap the denoiser without touching the transport.

**[AWS AI Agents](https://github.com/Ajaneeshwar/aws-ai-agents-analytics)** — agentic cloud-cost analytics on Bedrock AgentCore: tool orchestration, code execution, guardrails.
